# ADR-081: Gravar data e hora (LocalDateTime) no JSON com um adaptador do Gson

- **Status:** Aceita
- **Data:** 2026-11-26
- **Autores:** Grupo do projeto (Gilvan Pedro, Sidney Emanuel, Guilherme Scarcela, João Paulo e Dários Suess)

## Contexto

O `RegistroLog` (ADR-080) guarda a data e a hora do registro em `LocalDateTime`, porque o log
precisa da hora exata e não só do dia.
Na primeira gravação do log, o Gson falhou: nas versões recentes do Java ele não consegue
ler os campos internos de `LocalDateTime` sozinho. Foi o mesmo problema que já tinha
aparecido com `LocalDate` na data de nascimento (ADR-029).

## Decisão

> Vamos registrar um `TypeAdapter<LocalDateTime>` no Gson da `PersistenciaArquivo`, que grava
> a data e hora como texto ISO e lê de volta com `LocalDateTime.parse`, porque é a mesma
> solução que já funciona para `LocalDate`.

- Gravar: `"2026-11-26T08:59:47"` (o `toString()` do `LocalDateTime`). Nulo vira `null`.
- Ler: `LocalDateTime.parse(texto)`. `null` volta como `null`.
- O adaptador fica ao lado do de `LocalDate`, no mesmo `GsonBuilder`, e vale para todos os
  arquivos. Hoje só o log usa `LocalDateTime`; a `Solicitacao` guarda só o dia, em `LocalDate`,
  e usa o adaptador do ADR-029.

## Alternativas consideradas

### Alternativa 1: Guardar a data como `String` na entidade

- **Prós:** nenhum adaptador.
- **Contras:** comparar e ordenar datas vira comparar textos; cada lugar teria de converter.
- **Por que não foi escolhida:** o repository do log ordena pela data.

### Alternativa 2: Guardar como número (milissegundos)

- **Prós:** fácil de ordenar.
- **Contras:** ilegível no JSON.
- **Por que não foi escolhida:** o grupo abre os arquivos para conferir os testes.

## Consequências

### Positivas

- O log grava e carrega sem erro, e a ordem da pilha é refeita pela data e hora.
- O JSON fica legível.

### Negativas

- Mais um adaptador para lembrar se surgir outro tipo de data (`LocalTime`, `Instant`).

### Neutras

- Quando o banco entrar (ADR-065), a conversão passa a ser feita pelo driver do banco.

## Referências

- ADR-029 (adaptador de `LocalDate`), ADR-080 (`RegistroLog`).
