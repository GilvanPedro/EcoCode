# ADR-062: Implementar uma fila encadeada genérica no pacote Estrutura

- **Status:** Aceita
- **Data:** 2026-11-24
- **Autores:** Grupo do projeto (Gilvan Pedro, Sidney Emanuel, Guilherme Scarcela, João Paulo e Dários Suess)

## Contexto

As solicitações pendentes precisam de uma fila (ADR-051), atendida na ordem de chegada. O Java
já tem filas prontas (`LinkedList`, `ArrayDeque`), mas o projeto integrador pede que o grupo
aplique as estruturas de dados estudadas, implementadas por eles.

## Decisão

> Vamos criar o pacote `Estrutura` com uma fila encadeada genérica, `FilaEncadeada<T>`, feita
> com nós (`No<T>`), sem usar as coleções prontas do Java.

| Classe | Papel |
| --- | --- |
| `No<T>` | Guarda um valor e a referência para o próximo nó |
| `FilaEncadeada<T>` | Guarda o primeiro (início) e o último (fim) nó; entra pelo fim e sai pelo início |

```text
início                                fim
 [A] --> [B] --> [C] --> null
  ^ sai daqui            ^ entra aqui
```

- Com referência para o início e para o fim, entrar e sair da fila são operações de tempo
  constante, sem percorrer a fila.
- É **genérica** (`<T>`): a mesma classe serve para solicitações ou qualquer outro tipo.

## Alternativas consideradas

### Alternativa 1: Usar `LinkedList` ou `ArrayDeque` do Java

- **Prós:** pronto e testado.
- **Contras:** não mostra a implementação.
- **Por que não foi escolhida:** o trabalho pede a estrutura feita pelo grupo.

### Alternativa 2: Fila com vetor (circular)

- **Prós:** sem objetos de nó.
- **Contras:** tamanho fixo, ou cópia do vetor quando enche.
- **Por que não foi escolhida:** a fila encadeada cresce à vontade.

## Consequências

### Positivas

- A estrutura fica visível no código e na apresentação.
- O pacote `Estrutura` passa a ser o lugar das estruturas próprias (a AVL do ADR-049 e a pilha
  do log, ADR-052, podem ficar lá).

### Negativas

- O grupo é responsável por testar casos de borda: fila vazia, um elemento só, esvaziar e
  encher de novo.
