# ADR-079: Implementar uma pilha encadeada genérica no pacote Estrutura

- **Status:** Aceita
- **Data:** 2026-11-26
- **Autores:** Grupo do projeto (Gilvan Pedro, Sidney Emanuel, Guilherme Scarcela, João Paulo e Dários Suess)

## Contexto

O ADR-052 decidiu mostrar o log de auditoria como uma pilha, com o registro mais recente em
cima. O pacote `Estrutura` já tinha o `No<T>` e a `FilaEncadeada<T>` (ADR-062). Faltava a
pilha.

## Decisão

> Vamos criar a `PilhaEncadeada<T>` no pacote `Estrutura`, reaproveitando o `No<T>` da fila,
> porque a pilha é a estrutura que entrega primeiro o último que entrou (LIFO).

| Método | O que faz | Custo |
| --- | --- | --- |
| `empilhar(valor)` | O nó novo aponta para o topo antigo e vira o topo | O(1) |
| `desempilhar()` | Tira o topo e devolve o valor | O(1) |
| `espiar()` | Devolve o topo sem tirar | O(1) |
| `listar()` | Copia do topo para baixo, o mais recente primeiro | O(n) |
| `estaVazia()`, `tamanho()` | Consultas | O(1) |

```text
topo
 [C] --> [B] --> [A] --> null
  ^ entra e sai por aqui
```

- Empilhar `null` lança `IllegalArgumentException`; desempilhar ou espiar com a pilha vazia
  lança `IllegalStateException`.
- É genérica (`<T>`), como a fila.

## Alternativas consideradas

### Alternativa 1: Usar `java.util.Stack` ou `ArrayDeque`

- **Prós:** pronto e testado.
- **Contras:** não mostra a implementação, que é o que a disciplina avalia.
- **Por que não foi escolhida:** o grupo implementa as próprias estruturas (ADR-062).

### Alternativa 2: Pilha com vetor

- **Prós:** acesso por posição.
- **Contras:** precisa crescer o vetor quando enche.
- **Por que não foi escolhida:** a encadeada nunca enche e reaproveita o `No<T>`.

## Consequências

### Positivas

- Empilhar e desempilhar em tempo constante.
- `No<T>` serve agora para fila e pilha.

### Negativas

- `listar()` cria uma cópia a cada chamada; com um log muito grande, isso pesa.

### Neutras

- O log só usa `empilhar` e `listar`, porque um registro nunca é retirado (ADR-080).

## Riscos e pendências

- [ ] Se o log crescer muito, listar só os N mais recentes.

## Referências

- ADR-052 (log como pilha), ADR-062 (`No<T>` e `FilaEncadeada<T>`), ADR-080 (log de auditoria).
