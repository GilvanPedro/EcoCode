# ADR-065: Descartar o modo offline e guardar os dados só no banco de dados

- **Status:** Aceita
- **Data:** 2026-11-24
- **Autores:** Grupo do projeto (Gilvan Pedro, Sidney Emanuel, Guilherme Scarcela, João Paulo e Dários Suess)

## Contexto

A primeira versão dos requisitos do projeto integrador tinha o RNF04, disponibilidade offline: o app funcionaria
sem conexão, guardando os dados localmente e sincronizando depois. Ao mesmo tempo, o projeto
precisa de persistência em banco (RNF03), e o banco tinha sido adiado no ADR-042 até o
front-end estar ligado.

## Decisão

> Vamos descartar o modo offline e guardar os dados só no banco de dados, removendo o RNF04 dos
> requisitos. Decisão tomada pelo grupo.

- Sem cópia local para sincronizar: o banco é a única fonte dos dados.
- A AVL em memória (ADR-049) é só índice das buscas, não um modo offline.

## Alternativas consideradas

### Alternativa 1: Manter o modo offline

- **Prós:** o app funcionaria sem conexão.
- **Contras:** exige guardar os dados em dois lugares e resolver conflitos quando duas pessoas
  mudam a mesma coisa sem conexão.
- **Por que não foi escolhida:** o trabalho não cabe no prazo, e o app não precisa disso para
  cumprir os outros requisitos.

## Consequências

### Positivas

- Um lugar só para os dados, sem sincronização nem conflitos.
- Menos um requisito para implementar e testar.

### Negativas

- Sem conexão com o banco, o app não funciona.
