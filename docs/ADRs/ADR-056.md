# ADR-056: Representar Goiânia por um grafo de 15 bairros âncora

- **Status:** Aceita
- **Data:** 2026-11-23
- **Autores:** Grupo do projeto (Gilvan Pedro, Sidney Emanuel, Guilherme Scarcela, João Paulo e Dários Suess)

## Contexto

O Dijkstra (ADR-048) precisa de um grafo: vértices, arestas e pesos. Goiânia tem cerca de 600
bairros. Montar o grafo com todos eles exigiria saber quais bairros fazem divisa com quais e a
distância de cada ligação, à mão, para milhares de arestas.

## Decisão

> Vamos usar um grafo com 15 bairros âncora, espalhados pela cidade, ligando com arestas só os
> bairros vizinhos, porque é um tamanho que o grupo consegue montar e conferir à mão.

**Os 15 bairros**

| | | |
| --- | --- | --- |
| Setor Central | Setor Oeste | Setor Campinas |
| Setor Leste Universitário | Setor Bueno | Setor Marista |
| Jardim Goiás | Setor Pedro Ludovico | Jardim América |
| Parque Amazônia | Setor Jaó | Jardim Guanabara |
| Jardim Novo Mundo | Cidade Jardim | Jardim Curitiba |

- **Arestas:** só entre bairros vizinhos, com a distância como peso. A estimativa é de 25 a 35
  arestas, montadas à mão.
- **Pontos de coleta:** cada ponto fica ligado a um dos 15 bairros.
- **Empate:** se dois pontos ficarem à mesma distância, ganha o que tiver a menor fila de
  coletas.

## Alternativas consideradas

### Alternativa 1: Grafo com todos os ~600 bairros

- **Prós:** distância mais precisa para qualquer endereço.
- **Contras:** milhares de arestas para levantar e conferir à mão; inviável no prazo.
- **Por que não foi escolhida:** o custo de montar o grafo seria maior que o resto do projeto.

## Consequências

### Positivas

- Grafo pequeno, fácil de desenhar no relatório e de explicar na apresentação.
- O Dijkstra roda instantâneo.

### Negativas

- A distância é aproximada: quem mora num bairro fora da lista é tratado como se estivesse no
  bairro âncora mais próximo.

## Riscos e pendências

- [ ] Decidir como o usuário de outro bairro entra no grafo: uma tabela que aponta cada um dos
  ~600 bairros para o seu bairro âncora, ou o usuário escolher direto entre os 15.
- [ ] Levantar as arestas e as distâncias entre os vizinhos.
- [ ] RN11 (proposta): o bairro informado deve estar entre os cadastrados.
