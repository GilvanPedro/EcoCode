# ADR-050: Classificar os resíduos numa lista simples de categorias

- **Status:** Aceita
- **Data:** 2026-11-23
- **Autores:** Grupo do projeto (Gilvan Pedro, Sidney Emanuel, Guilherme Scarcela, João Paulo e Dários Suess)

## Contexto

O app precisa cadastrar e classificar os resíduos (RF02). O módulo da Missão 02 já
classificava pelo tipo (`TipoResiduo`, ADR-012) e pela categoria calculada pelo código
(ADR-004, ADR-015). No planejamento do projeto integrador apareceu a ideia de organizar as
categorias como uma árvore, com categorias e subcategorias (por exemplo, "Informática" com
"Notebook" e "Periférico" embaixo).

## Decisão

> Vamos classificar os resíduos numa lista simples de categorias, sem hierarquia, porque o
> app não precisa de subcategorias para funcionar.

- Cada resíduo pertence a uma categoria da lista.
- A classificação que já existe no código continua valendo.

## Alternativas consideradas

### Alternativa 1: Árvore de categorias (hierarquia)

- **Prós:** permitiria filtrar por grupo e subgrupo; usaria uma estrutura de árvore.
- **Contras:** mais telas, mais regras e mais dados para cadastrar, sem ganho real para quem
  vai descartar um celular.
- **Por que não foi escolhida:** complexidade sem necessidade. A estrutura de árvore do
  projeto já aparece na AVL (ADR-049).

## Consequências

### Positivas

- Simples de mostrar num filtro ou num campo de escolha.
- Reaproveita o que já existe no código.

### Negativas

- Se um dia for preciso agrupar categorias, a lista terá que virar outra estrutura.
